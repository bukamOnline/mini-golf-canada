Visiting Golf Miniature

Val-David's municipal directory calls this course Mini-golf Les Floralies and places it at 929 Route 117. It is distinct from Golf La Falaise, which appears directly above it in the same directory at a different Route 117 address.

Visit details checked September 7, 2026
Correct name and roadThe town lists Mini-golf Les Floralies at 929 Route 117, Val-David. Source
Contact distinctionThe municipal directory gives 819-322-1244 for Les Floralies, separate from La Falaise's 819-326-0616. Contact details in other older listings differ. Source
Seasonal leadA local hotel-area guide describes Les Floralies as open from May to mid-October, without a year-specific daily schedule. Source

Our planning take

Use the Les Floralies name and 929 street number when confirming the course. Verify the season's final opening day before an autumn trip; a general mid-October description does not promise every day is playable. Ask the municipality for an updated operator contact if the directory's number does not connect, rather than phoning La Falaise about this miniature course.

Tickets and budget

The municipal entry confirms the course identity but no tariff. Hotel-area season guidance is not a current admission offer.
