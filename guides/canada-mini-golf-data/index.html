Canada Mini Golf Directory Data

An original snapshot of Canadian mini golf directory coverage, course signals and source quality.

By Mini Golf Canada Research DeskUpdated August 28, 2026

2026 directory snapshot: Mini Golf Canada's publishable dataset contains 288 course profiles across 211 Canadian cities and towns. Source records were checked through August 28, 2026 and this analysis was recalculated on August 28, 2026. It measures this directory's evidence and gaps; it is not a census of every operating Canadian course.

What Mini Golf Canada measured

The report is calculated from the same normalized records used to build course, city and province pages. It counts a physical venue once after known parent-attraction and course-name aliases are consolidated. A profile enters public discovery when current source evidence passes the quality gate or when an established, accurate search page is retained while stronger source material is sought. Conflicting official evidence, unsupported new records and known non-course businesses do not enter the publishable sample.

The distinction between “missing” and “no” is important. If no source establishes an indoor setting, the report records the setting as unknown; it does not label the course outdoor. If a pricing page is ambiguous, a package amount is omitted rather than presented as mini-golf admission. A failed crawl is also unknown, not evidence of closure.

How complete is a typical listing?

Completeness is reported by field so a long page cannot hide weak evidence. “Publisher ready” is deliberately stricter than “indexable”: it requires source-confirmed mini golf, multiple references, concrete course detail and a minimum mix of useful planning fields. This rule keeps future ad code off searchable pages that still need stronger editorial support.

Course-format signals in the sample

Feature counts come from normalized public-profile fields and narrow statements in linked source text. One venue can appear in several rows because an indoor course may also offer glow play, parties and an arcade. A missing signal means “not established in this dataset,” not “the venue does not offer it.”

A setting is known for 103 profiles. The overlap analysis finds 25 profiles with both indoor and glow signals, 2 with both outdoor and seasonal signals, and 180 with at least one birthday, group or booking signal. These combinations are useful for planning filters, but they do not prove current availability for a particular date.

Where a hole count was explicit and passed the mini-golf context check, the most frequent values were 18-hole (109 profiles), 9-hole (27 profiles), 6-hole (2 profiles), 15-hole (1 profiles), 12-hole (1 profiles). The extractor ignores unrelated full-size golf holes and implausible numbers. Profiles without a qualifying count remain unclassified rather than being assigned the common 18-hole format.

Where directory choice is concentrated

The sample spans 211 municipalities, but coverage is uneven. 165 city or town pages currently have one publishable venue, while 7 have four or more. A one-course page is useful for locating and verifying that venue; it should not be read as proof that no other local course exists.

Reproducible method

  1. Normalize names, municipalities, province codes, addresses and public URLs from the source table.
  2. Merge known aliases when a parent venue and a named attraction describe the same physical destination.
  3. Retrieve venue, municipal, tourism and local source pages with Crawl4AI where available; retain crawl failures as neutral records.
  4. Extract only statements that explicitly mention mini golf, mini putt, miniature golf or a closely equivalent activity.
  5. Validate hole counts in nearby mini-golf context and reject unrelated golf-course numbers.
  6. Normalize features, schedules, contact routes, images and dated public-feedback context without copying individual reviews.
  7. Apply separate publishing, indexing and publisher-readiness gates, then run duplicate-copy, link, metadata and responsive-layout checks on the generated site.

Limits and update policy

  • Businesses open, close and change activities after a source check.
  • Small seasonal courses can have little or no crawlable web presence.
  • A failed crawler request is recorded as unavailable, never interpreted as closure.
  • Feature percentages describe known evidence, not nationwide prevalence.
  • Public ratings and schedules are dated snapshots and can change independently of this report.
  • Generated directory comparisons are calculations from the normalized dataset, not first-hand venue reviews.
  • Directory totals change only after a substantive listing or quality-gate update; rebuilding the site alone does not reset page dates.

This report is recalculated when the directory's publishing rules or underlying records materially change. The editorial policy explains source priority, corrections and automation, and the Research Desk page documents the review workflow. Venue owners can use the submission page to supply a current official URL and improve an existing profile.

Read the dataset as coverage, not a census

Counts describe the records that pass the current publishing rules on the stated build date. They do not prove that every Canadian course is included or that a missing feature is unavailable at a venue. Source coverage differs by province, operator website quality and the stability of public business information.

Duplicate parent-business and attraction records are consolidated before public totals are calculated. Explicit source facts are kept separate from structured-profile signals, and a crawler timeout is recorded as unknown. These rules make the report reproducible while limiting conclusions to what the dataset can actually support.

Record these details

  • Snapshot date and record count
  • Indexing and source-quality gate
  • Duplicate consolidation rules
  • Meaning of missing feature signals
  • Correction and update process

Keep the source URL and check date with the notes. Unknown information should remain unknown until a current source or the venue resolves it; that distinction is more useful than a confident guess.
